# MIROTECH — version mise à jour

Cette version conserve les quatre fiches produits et leurs images, les variantes et prix, ainsi que le design existant.

Modifications demandées :
- bouton du formulaire renommé « Passer ma commande » ;
- popup de confirmation après le clic, indiquant que la demande a été préparée ;
- ouverture de WhatsApp avec le récapitulatif de commande.

Important : la popup ne peut pas prouver que le client a appuyé sur « Envoyer » dans WhatsApp, ni garantir que Google Sheets a enregistré la commande. L'enregistrement Sheets doit être testé séparément.

Pour publier : téléverser le contenu du dossier `mirotech-store` dans le dossier public du site sur l'hébergement, sans supprimer les sauvegardes précédentes.
